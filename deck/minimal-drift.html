Problemthe intent gap

AP2 binds the transaction. It does not bind the decision that produced it.

The cryptography is real and it works. The intent, the cart and the payment are each signed; the hashes chain; the amount is inside the cap. Every one of those checks passes on the record above.

And none of them say the agent bought the right thing. An agent choosing from a merchant’s result set is choosing on information it never verified — labels, ordering, the rationale beside the price, what it thinks it remembers you preferring. Each of those is writable by whoever supplies the catalog.

So the attack surface is not the signature. It is the sentence next to the price.

Objectivefour constraints

Not “can we break it”. How little does it take, provably, and does it move?

ConstraintWhat it stops us claiming
minimise C(δ)“We broke it” — with a 40-field prompt nobody would ship
ATE ≥ τ, CI>0, >εCrediting the agent’s own error rate to our attack
V(δ) = 1Calling a payment a PSP would reject a successful attack
R(δ) ≥ ρShipping an artefact of one model on one catalog

C(δ) is the perturbation cost — fields, tokens, turns, surfaces touched. The reported quantity is |δ*|: the certified-minimal number of changed fields that flips a valid payment’s purchased object, net of baseline error, and transfers to targets the search never saw.

Methodthe loop

The validity gate comes first, so a wasted query is impossible.

  • An out-of-mandate candidate costs nothing. The constraint engine is pure and deterministic, so invalid candidates are discarded before a single target query. Query budget is spent only on payments that would clear.
  • The unit of evidence is a matched pair, not a success. Same session seed, same intent paraphrase, same retrieval jitter — the only difference between the two arms is δ. Attributable requires lower CI > 0 and ATE ≥ τ and ATE > ε.
  • Reflection is typed by the boundary that stopped you. Blocked at the user’s confirmation screen → add a consent operator. Filtered every option away → relax, don’t escalate. The reply to a refusal is a change of strategy, not of wording.
  • The archive stores the minimum, not the maximum. Elite selection is lexicographic with min C(δ) first, so each behavioural cell holds the cheapest attack that works — then delta debugging shrinks it further.

Six mechanisms, measured alone

ranking · 0.850

Agents over-weight the first result. The control that tells us how much of an attack is really just position.

omission · 0.850

Delete the discriminating attribute. Asserts nothing false, which is what makes it hard to fire on.

memory · 0.850

Plant a remembered constraint, not a preference. One requirement eliminates every faithful option.

metadata · 0.779

Make a different object look like the requested one. Never reaches the user — the signed cart does.

tool_output · 0.637

The merchant’s own API response as the vehicle. Effective, and the only loud one.

consent · 0.000

Reframe the confirmation so nothing is disclosed. Changes no agent decision — it removes the last check on a decision another mechanism already moved. Necessary, never sufficient.

The defensible combination

  • The attacker searches strictly inside the valid payment space. The validator is a hard constraint, not a scoring term — so no finding can be dismissed as a malformed request.
  • Success is a counterfactual, not an outcome. We report intents where ε is non-zero, and attacks whose CI touches zero, as failures.
  • Minimality is the objective, not a footnote. The reported number is certified by delta debugging against the full constraint set.
  • Two defenders, one held out from fitness. The in-loop checker reads language; the held-out one reads only the shape of the decision. Optimising against one and being scored by the other is what reveals whether the attacker learned the checker or the vulnerability.
  • Both defenders have a measured false-positive rate of 0.0000 over 120 clean runs. A stealth score against a checker that fires on honest traffic measures nothing.

Defencewhat works

Three controls, measured rather than recommended.

  • requires_refundability = true in the IntentMandate is a real control. It removes every stored-value drift target on the six intents that set it — asserted as a test. Two of ten intents become unattackable at τ = 0.30 outright. AP2 already ships the field.
  • Disclose the merchant-signed cart at confirmation, and never let the agent author that string. The disclosure renders from the signed mandate, so no amount of feed relabelling reaches the user. In this environment the consent surface is the only route past a vigilant one.
  • Structural monitoring catches what language monitoring cannot. A pure ranking attack introduces no text and is invisible to the alignment checker — asserted as a test. The schema-outlier check catches it without reading a word.
Limitswhat this does not show

The honest weak points, listed rather than buried.

  • The target is a surrogate agent, not an LLM. The live path is verified end to end — with a key set, the harness drives gemini-2.5-flash through the full AP2 flow to a signed, validator-valid PaymentMandate — but the free tier allows 20 requests per day per model against a sweep needing roughly 2,000, so every figure here is against a documented deterministic linear-scoring shopper whose susceptibilities are the reported failure modes of LLM shopping agents. Every result records the model_id it truly ran against.
  • Live models: one attack transfers, twenty do not. The full archive (8 elites) replayed unchanged against 3 real Gemini models, 6 seeds/arm, cleared the attributability bar 4 of 24 times. omission × retrieval at |δ*| = 1 drifted every live model zero-shot (ATE 0.375 / 0.500 / 0.500) — the claim surviving contact with a real LLM. The other 20 did not, and the memory mechanisms that dominate the surrogate archive moved these models not at all: a surrogate-tuned archive is not a set of working LLM attacks. Six seeds, one vendor, two members whose endpoint rejects seed; kept as its own report section and never averaged into the headline.
  • Transfer is not cross-vendor. Five surrogate weight profiles plus Environment B. The report and the demo both say so unprompted.
  • The catalog is synthetic. Rupee figures are meaningful as ratios, not as market losses.
  • The cell → taxonomy mapping is our judgement. Coverage against it is a structured argument, not an audited score.

Both of the first two are single-environment-variable fixes. Neither is papered over anywhere in the code, the report, the deck or the demo.
